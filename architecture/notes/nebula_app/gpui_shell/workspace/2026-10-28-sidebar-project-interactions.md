# 项目交互与固定目录分支快照

## Status

Implemented；S5 验证结果见 [路线图](../../../../../ROADMAP.md)。

## Context

[Pane 分组](2026-10-27-pane-project-binding.md)按固定项目目录投影，终端及分屏树仍归 Tab 所有。
折叠和置顶需要改变窗口内的展示，但不能停止会话、迁移 Pane 或改变项目归属。
当前活动 Pane 的 cwd 可以与项目目录不同，VCS 面板的当前目录不能代表所有项目。
分支查询涉及子进程，必须独立于渲染，并与窗口、项目的生命周期一致。

## Evidence

- [分组模型](../../../../../nebula_app/src/gpui_shell/workspace/pane_groups/model.rs)保留首次出现顺序，
  关闭最后一个 Pane 后删除该组；每个窗口独立拥有模型。
- [共享短期探测](../../../../../nebula_app/src/platform/process_output.rs)已有取消、输出上限、
  超时和进程组回收能力，无需重新实现线程或子进程管理。
- [控件回归](../../../../../nebula_app/src/gpui_shell/workspace/pane_sidebar/tests.rs)曾复现项目头外边距
  导致最后一项滚动定位多出 8 像素；把间距纳入项目头自身高度后，原边界断言通过。
- 四个 Windows 原生窗口场景覆盖 Nord/Paper、中英文、220/300 像素侧栏。
  隐藏 Pane 的真实 CMD 任务完成后仍可读取输出；另一项目处于前台时，折叠项目的分支仍独立更新。

## Decision

- 折叠和置顶保留在窗口内的分组模型中，不增加持久化字段。
  侧栏隐藏折叠组的行，保留所有 Pane 的归属与运行状态；关闭该组最后一个 Pane 后丢弃偏好。
  显式导航或在项目中新建会话时展开目标组，避免焦点落到不可见条目。
- 置顶使用原始组列表的稳定分区：先枚举置顶组，再枚举其余组。
  不重排所有权列表或 Pane 列表；取消置顶自然恢复首次出现顺序。
- [分支快照](../../../../../nebula_app/src/gpui_shell/workspace/pane_sidebar/branches.rs)属于窗口侧栏，
  使用固定项目目录，复用现有一秒 watchdog 驱动，五秒缓存，每批最多查询四个项目。
  优先处理未查过及最久未查的目录，避免慢仓库连续占用批次、饿死后续项目。
- [分支读取](../../../../../nebula_app/src/display/side_panel/vcs.rs)只运行
  `git --no-optional-locks symbolic-ref --quiet --short HEAD`，不扫描索引或完整工作区状态。
  清除可重定向仓库的继承环境变量；不弹控制台，每次限时两秒、输出最多 4096 字节。
  非 Git、目录不可用、detached HEAD、失败和取消均隐藏分支，不渲染错误占位。
- 每个窗口最多保留一个后台批次任务。隐藏整个侧栏、切离侧栏模式、项目成员变化及窗口销毁时取消。
  项目移除后重新创建获得新 generation，旧结果不能覆盖新组；关闭窗口后的弱引用不能写回。
- [项目头](../../../../../nebula_app/src/gpui_shell/workspace/pane_sidebar/project_header.rs)预留分支行高度，
  避免异步结果出现时移动 Pane；组间间距使用内边距，纳入 `ScrollHandle` 的真实条目边界。
  折叠区支持 Enter、Space、左右方向键；置顶和新建沿用现有按钮及主题状态。
  树形缩进和连接线只呈现归属，未增加排序或拖动协议。

## Rejected alternatives

- 折叠时移除或暂停终端：展示偏好会改变会话生命周期。
- 原地排序组列表：取消置顶后无法直接恢复原始出现顺序，并会混淆已有模型合同。
- 读取当前 Pane cwd 或共享 VCS 面板状态：切换焦点或执行 `cd` 后会把分支串到其他项目。
- 渲染时执行 Git 或为每组新增定时器：阻塞 UI 或增加无所有者的周期工作。
- 复制完整 VCS 状态扫描：项目头只需要 HEAD，扫描成本和状态耦合均无必要。
- 每次固定取前四个过期条目：四个两秒探测超过缓存周期后，可让其余项目一直拿不到首次结果。

## Consequences

本次仅启用 Windows 本地项目侧栏，不增加依赖、设置或恢复格式。
分支是有界的周期快照，项目多或 Git 较慢时更新会延迟；不是文件监听或实时状态承诺。
会话迁入新窗口沿用目标窗口的组偏好，重新打开已消失项目使用默认展开、未置顶状态。

## Validation

- 模型和控件回归覆盖稳定置顶与恢复、折叠后同步、显式导航展开、新建展开、左右键、
  关闭后重开及窗口隔离、窄侧栏边界、滚动、主题和语言切换。
- 分支回归使用独立临时 Git 仓库，覆盖 Unicode 分支、切换、linked worktree、detached HEAD、
  非 Git、缺失目录、取消、过期结果及慢批次公平性。
- [原生夹具](../../../../../nebula_app/src/gpui_shell/workspace/pane_sidebar/native_tests.rs)在自有窗口内
  按真实控件边界分发事件，验证折叠不停进程、固定目录分支刷新、置顶/取消、选中与单 Pane 关闭。
  截图已核对；预览正文为隔离夹具注入，本次不替代 S4 的真实 CLI 接受链路或 S6 的便携包人工验收。

需要持久化项目偏好、支持其他平台/远端项目、超大项目列表，或分支快照需要改为事件驱动时重新评估。
